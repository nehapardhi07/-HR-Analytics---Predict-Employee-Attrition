# 📊 HR Analytics - Employee Attrition Prediction

## 📌 Project Overview
This project focuses on analyzing employee data to understand the key factors behind employee attrition (resignation) and predicting future attrition .

The goal is to help organizations reduce employee turnover by identifying patterns and providing data-driven insights.

---

## 🎯 Objective
- Analyze HR data to find reasons for employee attrition  
- Build a predictive model to identify employees likely to leave  
- Visualize insights using an interactive dashboard  
- Provide actionable recommendations to reduce attrition  

---

## 🛠️ Tools & Technologies
- Python
  - Pandas (Data Cleaning & Analysis)
  - Seaborn & Matplotlib (Visualization)
- Google Colab (Data cleaning, preprocessing, model building)
- Power BI (Dashboard visualization)

---

## 📂 Project Workflow

### 1. Data Cleaning (Google Colab)
- Handled missing values  
- Removed duplicates  
- Converted data types  
- Feature selection and preprocessing  

### 2. Exploratory Data Analysis (EDA)
- Attrition by Age  
- Attrition by Salary  
- Attrition by Job Role  
- Attrition by Education  
- Attrition by Years at Company  

---

## 📊 Dashboard Insights
- Total Employees: 1470  
- Attrition Count: 237  
- Attrition Rate: 16.1%  
- Average Age: 37  
- Average Salary: 6.5K  

### Key Findings
- High attrition in low salary group (≤ 5K)  
- Age group 26–35 has highest attrition  
- Laboratory Technicians and Sales Executives show high turnover  
- Higher attrition in early years of employment  

---

## 📁 Deliverables
- Power BI Dashboard  
- Model Accuracy Report + Confusion Matrix  
- Attrition Analysis Report
